🎯 가장 쉬운 사용 방법 (3단계)

1단계: 패키지 설치 (최초 1회만)
   Windows: install_packages.bat 더블클릭
   Mac/Linux: install_packages.sh 더블클릭

2단계: 프로그램 실행
   GUI 버전 (추천): run_gui.bat (또는 run_gui.sh) 더블클릭
   CLI 버전: run_cli.bat (또는 run_cli.sh) 더블클릭

3단계: 검색 시작!

================================================================================

📁 파일 설명

실행 파일:
- run_gui.bat / run_gui.sh         → GUI 버전 실행 (더블클릭)
- run_cli.bat / run_cli.sh         → CLI 버전 실행 (더블클릭)
- install_packages.bat / install_packages.sh → 패키지 설치 (더블클릭)

프로그램 파일:
- semantic_scholar_search_gui.py   → GUI 프로그램
- semantic_scholar_search.py       → CLI 프로그램
- requirements.txt                 → 필요한 패키지 목록

문서:
- README.md                        → 상세 사용 설명서
- 사용방법.txt                     → 이 파일

💡 팁

1. GUI 버전 (run_gui.bat)이 가장 쉽습니다!
   - 마우스로 클릭만 하면 됩니다
   - 진행 상황을 실시간으로 볼 수 있습니다

2. 바탕화면에 바로가기 만들기
   - run_gui.bat 파일을 우클릭
   - "바로가기 만들기" 선택
   - 바탕화면으로 드래그

3. API 키 설정 (선택사항)
   - GUI 버전: 프로그램 실행 후 상단에 입력
   - CLI 버전: semantic_scholar_search.py 파일 열어서 API_KEY 변수에 입력

❓ 문제 해결

Q: "Python을 찾을 수 없습니다" 오류가 나요
A: Python을 먼저 설치하세요
   https://www.python.org/downloads/
   설치 시 "Add Python to PATH" 체크!

Q: "패키지를 찾을 수 없습니다" 오류가 나요
A: install_packages.bat (또는 .sh) 파일을 더블클릭하세요

Q: GUI가 열리지 않아요 (Linux)
A: 터미널에서 실행: sudo apt-get install python3-tk

Q: Mac에서 실행이 안돼요
A: 터미널에서 한 번만 실행:
   chmod +x run_gui.sh
   chmod +x run_cli.sh
   chmod +x install_packages.sh
