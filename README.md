# 파일 이름 일괄 변경 프로그램 (Mac용 GUI)

맥 환경에서 사용 가능한 파일 이름 일괄 변경 GUI 프로그램입니다.

## 주요 기능

### 기본 기능
- 📁 **폴더 선택**: 변경할 파일들이 있는 폴더를 선택
- 🏷️ **접두사/접미사**: 파일 이름 앞뒤에 텍스트 추가
- 🔍 **찾기/바꾸기**: 특정 텍스트를 찾아서 다른 텍스트로 변경
- 🔢 **순차 번호**: 파일에 자동으로 번호 매기기 (001, 002, 003...)
- 👀 **미리보기**: 변경 전에 어떻게 바뀔지 확인
- ⚡ **일괄 실행**: 한 번에 모든 파일 이름 변경

### 고급 기능
- 🌓 **다크/라이트 모드**: 눈에 편한 테마 전환
- 🔽 **파일 필터**: 확장자별로 파일 필터링 (.jpg, .pdf 등)
- 🔤 **대소문자 변환**: 대문자, 소문자, 타이틀 케이스로 변환
- 📝 **정규표현식**: 고급 패턴 매칭으로 복잡한 변경 작업
- ⏪ **실행 취소**: 실수로 변경한 파일 이름 복원 (Cmd+Z)
- 📂 **최근 폴더**: 자주 사용하는 폴더 빠른 접근
- 🧹 **특수문자 처리**: 공백 제거/변경, 특수문자 정리

## 설치 방법

Python 3가 필요합니다. 맥에는 기본적으로 Python이 설치되어 있습니다.

```bash
# 저장소 클론
git clone <repository-url>
cd joe

# 실행 권한 부여
chmod +x batch_rename_gui.py
```

## 사용 방법

### 터미널에서 실행

```bash
python3 batch_rename_gui.py
```

또는

```bash
./batch_rename_gui.py
```

### 사용 순서

1. **폴더 선택** 버튼을 클릭하여 파일이 있는 폴더 선택
2. (선택사항) 파일 필터에서 특정 확장자만 선택
3. 원하는 탭에서 옵션 선택:
   - **접두사/접미사 탭**: 파일 이름 앞이나 뒤에 텍스트 추가
   - **찾기/바꾸기 탭**: 특정 텍스트를 찾아서 변경 (정규표현식 지원)
   - **순차 번호 탭**: 파일에 번호 매기기
   - **대소문자 탭**: 대소문자 변환
   - **특수문자 탭**: 공백 및 특수문자 처리
4. **미리보기** 버튼으로 변경 결과 확인
5. **실행** 버튼으로 실제 파일 이름 변경
6. (필요시) **실행 취소** 버튼으로 되돌리기

### 키보드 단축키

- `Cmd+Z`: 실행 취소
- 메뉴바의 다른 단축키들도 사용 가능

## 사용 예시

### 예시 1: 접두사 추가
- 접두사: `vacation_`
- `photo1.jpg` → `vacation_photo1.jpg`
- `photo2.jpg` → `vacation_photo2.jpg`

### 예시 2: 찾기/바꾸기
- 찾을 텍스트: `IMG`
- 바꿀 텍스트: `Photo`
- `IMG_001.jpg` → `Photo_001.jpg`

### 예시 3: 순차 번호 추가
- 시작 번호: 1
- 자릿수: 3
- 위치: 뒤
- `document.pdf` → `document_001.pdf`
- `report.pdf` → `report_002.pdf`

### 예시 4: 대소문자 변환
- 대소문자: 모두 소문자
- `MyDocument.PDF` → `mydocument.pdf`
- `REPORT_2024.TXT` → `report_2024.txt`

### 예시 5: 특수문자 처리
- 공백을 '_'로 변경
- `my document.txt` → `my_document.txt`
- `vacation photo 2024.jpg` → `vacation_photo_2024.jpg`

### 예시 6: 정규표현식 사용
- 찾을 텍스트: `\d{4}` (4자리 숫자)
- 바꿀 텍스트: `2025`
- 정규표현식 사용: 체크
- `photo_2024.jpg` → `photo_2025.jpg`
- `report_2023_final.pdf` → `report_2025_final.pdf`

### 예시 7: 확장자 필터링
- 파일 필터: `.jpg`를 선택하면 JPG 파일만 보임
- 다른 확장자 파일들은 변경되지 않음

### 예시 8: 조합 (복합 작업)
접두사 + 대소문자 + 순차 번호를 함께 사용:
- 접두사: `2024_`
- 대소문자: 모두 소문자
- 순차 번호: 켜짐, 시작 1, 자릿수 3, 위치 뒤
- `Photo.JPG` → `2024_photo_001.jpg`

## 주요 기능 설명

### 다크/라이트 모드
- **메뉴바** → **보기** → **다크 모드** 체크/해제
- 설정은 자동으로 저장되어 다음 실행 시에도 유지됩니다

### 파일 필터
- 폴더를 선택하면 확장자 목록이 자동으로 생성됩니다
- 원하는 확장자를 선택하면 해당 파일만 표시/변경됩니다
- 예: `.jpg`만 선택하면 JPG 파일만 이름이 변경됩니다

### 정규표현식
- 고급 사용자를 위한 강력한 패턴 매칭 기능
- 예시:
  - `\d+`: 모든 숫자
  - `[A-Z]+`: 대문자 연속
  - `(IMG|Photo)_(\d+)`: 그룹 캡처 및 참조

### 실행 취소
- **편집** → **실행 취소** 또는 `Cmd+Z`
- 마지막으로 실행한 이름 변경 작업을 되돌립니다
- 여러 번 실행 취소 가능 (히스토리 유지)

### 최근 폴더
- **파일** → **최근 폴더**에서 최근 사용한 폴더 빠르게 접근
- 최근 10개 폴더가 자동으로 저장됩니다

## 주의사항

⚠️ **실행 취소 기능이 있지만 신중하게 사용하세요!**
- 변경 전에 반드시 **미리보기**로 확인하세요
- 중요한 파일은 백업을 먼저 만드세요
- 같은 이름의 파일이 있으면 변경이 실패합니다
- 실행 취소는 프로그램을 종료하면 히스토리가 사라집니다

## 시스템 요구사항

- Python 3.6 이상
- tkinter (Python 기본 포함)

## 문제 해결

### "tkinter를 찾을 수 없습니다" 오류

맥에서는 Python과 함께 tkinter가 설치되어 있어야 합니다:

```bash
# Homebrew로 Python 재설치
brew install python-tk@3.11
```

### GUI가 실행되지 않을 때

터미널에서 다음 명령어를 실행하여 오류 메시지를 확인하세요:

```bash
python3 batch_rename_gui.py
```
